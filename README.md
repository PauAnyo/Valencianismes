# 🍊 Valencianismes

> Descobreix el tresor del nostre vocabulari · Aplicació web i mòbil (PWA)

**Creat per Pau Anyó Calabuig**

---

## ✨ Característiques

- 📅 **Paraula del dia**: Cada dia una paraula típica i autèntica valenciana seleccionada automàticament.
- 🔀 **Explorador aleatori**: Descobreix nous valencianismes amb un sol clic.
- 📖 **193 valencianismes autèntics**: Paraules genuïnes, amb definició, exemples reals d'ús i traducció al castellà.
- 🎵 **Música instrumental de fons**: Ambient suau relaxant amb control de so (activar / silenciar).
- 📱 **Progressive Web App (PWA)**: Instal·lable a la pantalla d'inici en Android i iPhone (iOS) com una app nativa, funcionant fins i tot sense connexió a internet.

---

## 🚀 Accés i Instal·lació

- **Web directa**: [valencianisme.html](valencianisme.html)
- **Instal·lació en mòbil**:
  - **Android (Chrome)**: Menú de 3 punts > «Afegeix a la pantalla d'inici» o «Instal·la l'aplicació».
  - **iPhone (Safari)**: Botó Compartir ⬆️ > «Afegeix a la pantalla d'inici».
